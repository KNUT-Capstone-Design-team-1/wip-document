- AI를 활용한 알약 검색 애플리케이션 `이게뭐약` 개발 프로젝트

- `보건/의료 관련 업계 종사자`와 `의약품 복용자`에게 의약품을 편리하게 관리할 수 있도록 상세한 정보와 관리 기능을 제공하는 애플리케이션을 개발
