# 프로젝트 소개

- AI를 활용한 알약 검색 애플리케이션 `이게뭐약` 개발 프로젝트

# 프로젝트의 목표

- 의약품을 자주 다루는 **보건/의료 업계 종사자** 및 **환자의 보호자**가 복잡한 의약품 정보를 보다 쉽고 정확하게 식별할 수 있도록 지원
- 의료 현장과 가정 등 어디서든 안전하고 편리하게 의약품을 관리할 수 있는 맞춤형 통합 애플리케이션 개발
