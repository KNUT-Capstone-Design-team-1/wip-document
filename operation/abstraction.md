# 서비스 및 기능 정의

> AI 기반 의약품 검색 및 상세 정보 제공, 복용 관리, 편의 기능 제공 애플리케이션 서비스

`의약품`은 서비스의 검색·상세 정보·관리 대상을 설명하는 기본 용어입니다. `알약`은 사진이나 낱알 외형을 이용하는 식별 기능에서 사용합니다. 영양제는 별도 건강기능식품 데이터로 검색하며 의약품과 구분합니다. 기존 코드의 `pill_*` 식별자는 그대로 유지합니다.

| 기능                | 코드 모듈                                   | 역할                                                                         |
| ------------------- | ------------------------------------------- | ---------------------------------------------------------------------------- |
| 홈                  | `home`                                      | 검색 진입, 기능 메뉴, 최근 조회 의약품 확인                                  |
| 의약품 통합 검색    | `unified_search`                            | 원격 키워드 검색 후 품목번호로 로컬 의약품 조회                              |
| 알약 식별 검색      | `pill_identification_search`                | 문자·제품명·회사명·제형·모양·색상·분할선·마크로 로컬 검색                    |
| AI 알약 이미지 검색 | `pill_image_search`                         | 앞뒷면 사진에서 원격 AI로 특징 추출 후 로컬 후보 검색                        |
| 의약품 검색 결과    | `pill_search_result_list`                   | 세 검색 경로의 결과, 추가 로드, 조건 확인·재검색, 상세 진입                  |
| 의약품 상세 정보    | `pill_search_result_detail`                 | 로컬 기본 정보와 원격 상세 문서, 참고 분류, 키워드 찾기, 저장·재고 문의 연결 |
| 영양제 검색·상세    | `functional_food_search`                    | 제품명·업체명·제품 형태 검색, 제품·원재료·기능성 기준 조회, 저장             |
| 보관함              | `pill_save`                                 | 의약품·영양제 로컬 저장, 폴더 분류·정렬, 이동·복사·삭제                      |
| 복용 관리           | `pill_reminder`                             | 대상별 복용량, 복수 시간·요일·제목·메모, 로컬 알림 예약·수정·활성화·삭제     |
| 주변 약국·재고 문의 | `nearby_pharmacy`                           | 위치·지도 재검색, 클러스터·목록, 영업 중 필터, 주소 복사·전화 연결           |
| 공지·설정           | `notice`, `setting`                         | 공지·필독 안내, 약관, 앱·DB 버전, 최근 조회 기록·모든 복용 알림 삭제         |
| 공통 기능           | `database_update`, `guide`, `ads`, `shared` | 데이터 동기화, 사용 가이드, 광고, 공통 UI                                    |

## 복용 관리의 범위

현재 구현은 보관함과 복용 일정·알림 관리입니다. 알림의 '복용 완료' 액션은 안내 토스트를 표시합니다. 장기 복용 이력이나 복약 순응도 통계를 저장하는 기능으로 설명하지 않습니다. 복용 알림은 `expo-notifications`를 통한 기기 로컬 예약입니다.

## 데이터 및 네트워크 범위

식별 검색, 영양제 검색과 약국 목록 조회는 동기화된 로컬 DB를 사용합니다. AI 분석, 통합 검색, 의약품 상세 문서, 공지와 데이터 업데이트는 네트워크를 사용합니다. 로컬 데이터가 필요한 기능은 먼저 해당 데이터 동기화를 완료해야 합니다. 재고 문의는 약국 전화 연결을 지원하며 실시간 재고를 조회하지 않습니다.

구현 근거는 [애플리케이션 구조](../development/application_architecture.md), 화면 연결은 [화면 흐름](../diagram/screen_flow.md)을 참고합니다.
