# 공지사항 작성 규칙

공지 목록·상세·필독 안내는 앱의 `notice` 기능과 `wip-serverless/src/cloud_flare/wip-notice/`에서 처리합니다.

1. `title`과 `contents`를 작성합니다. 본문은 텍스트와 지원되는 이미지 표현을 사용하고, 저장되는 개행이 앱에서 정상 표시되는지 확인합니다.
2. 최초 작성일과 수정일을 구분합니다. 실제 API가 생성·수정 시 날짜를 처리하는 방식은 서버 구현에 맞춥니다.
3. `mustRead`는 필독 공지일 때 1, 일반 공지일 때 0입니다.
4. 필독 공지는 메인 바텀시트와 목록의 필독 표시·정렬을 함께 확인합니다.
5. 제품 소개에서는 '의약품 검색·상세 정보·복용 관리·편의 기능'을 기본 범위로 표현합니다. 알약 식별과 영양제 검색은 해당 기능을 지칭할 때 구분합니다.
6. 새 기능은 실제 배포 버전에서 제공되는지 확인한 뒤 공지합니다.

이전 문서의 예시 이미지 파일은 저장소에 없어 제거했습니다. 표시 검증은 [공통 기능 테스트](../test/12_common_features.md)를 참고합니다.
