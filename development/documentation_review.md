## 문서에서 바로잡은 차이

- 이미지 검색은 원격 특징 추출 후 로컬 후보 목록으로 이동하며 상세 직행이 아닙니다.
- 통합 검색은 limit 100·커서 기반 추가 로드를 사용하며 최대 50건 고정이 아닙니다.
- 보관함의 기본 폴더 정렬은 이름순입니다.
- 의약품과 영양제를 공통 보관·알림 대상으로 관리하며 영양제 키에 `functional-food:` 접두어를 사용합니다.
- 복용 알림은 기기 로컬 예약입니다. 완료 액션은 토스트이고 장기 복용 이력 저장은 없습니다.
- 약국 문의는 전화 연결이며 실시간 재고 응답을 제공하지 않습니다.
- 실제 코드에서 확인되지 않은 게이트웨이 노드와 Python 전용 백엔드 설명을 제거했습니다.
- 앱이 백그라운드에서 영구 실행된다는 보장과 전체 동기화 원자적 롤백을 구분했습니다.
- 동기화의 행 개수 검증은 기대 건수가 양수인데 실제 삽입이 0건인 경우를 감지합니다. 전체 건수 일치를 보장한다고 설명하지 않습니다.

## 남겨 둔 운영 확인 사항

- 실제 스토어 배포 버전과 코드 버전은 다를 수 있습니다.
- 리소스 정기 갱신일은 기존 운영 목표이며 실행 스케줄·최근 배포 성공은 코드만으로 확인되지 않습니다.
- 개인정보 처리방침과 이용약관에는 종전 검색 중심 문구가 남아 있습니다. 위치·광고·원격 이미지 처리·로컬 보관 및 알림에 대한 실제 운영 정책과 고지 내용의 일치는 별도 정책 검토 사항입니다. 이 기록은 법률 적합성 판단이 아닙니다.
- 기기 권한·OS 알림·지도·광고와 실제 서버 연동은 수동 검증 항목이며 이번 문서 변경으로 통과했다고 표시하지 않습니다.
