# 백엔드 코드 컨벤션

## 파일 및 변수 네이밍
- **소스코드 파일 (py)**: 스네이크 케이스 (snake_case)
- **변수명**: 스네이크 케이스 (snake_case)
- **함수명**: 스네이크 케이스 (snake_case)
- **클래스명**: 파스칼 케이스 (PascalCase 또는 UpperCamelCase)

## 일반적인 백엔드 규칙
- RESTful API 설계 원칙을 준수한다.
- 요청(Request) 및 응답(Response)의 형식(DTO)을 명확하게 정의하고 검증한다.
- 비즈니스 로직은 컨트롤러나 라우터에 두지 않고 별도의 서비스 계층(Service Layer)으로 분리한다.
- 예외 처리를 전역적으로 관리하고, 클라이언트에게 일관된 에러 응답 포맷을 제공한다.
- DB 쿼리는 직접 작성하는 것보다 ORM을 적절히 활용하되, 복잡한 쿼리의 경우 성능을 고려하여 최적화한다.
