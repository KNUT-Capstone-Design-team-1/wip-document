# 영양제 검색·상세

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분      | 확인 절차 및 기대 결과                                                                                         |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| 사전 조건 | 건강기능식품 제품·분류 테이블의 동기화를 완료한다. 기존 설치에서 두 테이블이 없던 경우도 확인한다.             |
| 검색      | 제품명·업체명·제품 형태를 각각 및 조합해 검색하고 형태 칩 재선택 시 조건이 해제된다.                           |
| 기본 목록 | 최초 진입 시 기본 조회를 수행하고 결과 수·빈 결과·조회 실패 안내를 확인한다.                                   |
| 페이지    | 페이지당 30개를 추가하고 중복 로드를 방지한다. 새 조건 제출 중 이전 응답이 새 목록을 덮지 않는다.              |
| 상세      | 품목제조신고번호로 제품·원재료·섭취 방법·주의사항·보관 방법과 연결된 기능성 기준을 표시한다.                   |
| 누락 정보 | 연결 분류·제품 형태·일부 상세 정보가 없어도 오류 없이 표시한다.                                                |
| 외부 링크 | 식품안전나라 버튼에서 외부 페이지를 연다.                                                                      |
| 저장·복용 | 상세에서 폴더에 저장하고 보관함에서 같은 영양제 상세로 재진입한다. 복용 알림에서 해당 영양제를 선택할 수 있다. |

구현 근거: `src/features/functional_food_search/`, `src/services/database/queries/functional_food.ts` (앱 저장소).
