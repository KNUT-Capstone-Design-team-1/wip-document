# 설정

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분           | 확인 절차 및 기대 결과                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| 화면 연결      | 앱 정보·이용약관·공지사항에서 각각의 라우트로 이동한다.                                                 |
| 버전           | 앱 정보에서 앱 버전과 9개 리소스 테이블의 스키마·데이터 버전을 표시하고 없는 값은 대체 표시한다.        |
| 최근 조회 삭제 | 기록 삭제 확인 모달에서 취소 시 보존, 확인 시 최근 조회 의약품을 삭제한다. 최근 검색어 삭제와 구분한다. |
| 모든 알림 삭제 | 표시된 알림 개수를 확인하고 삭제를 승인하면 DB 일정과 예약된 로컬 알림이 제거된다.                      |
| 알림 없음      | 알림이 0개일 때 전체 삭제 액션이 불필요한 확인·오류를 발생시키지 않는다.                                |
| 복귀           | 다른 화면에서 알림 추가·삭제 후 설정에 복귀하면 최신 개수가 반영된다.                                   |

구현 근거: `src/features/setting/hooks/use_setting.ts`, `services/setting_service.ts` (앱 저장소).
