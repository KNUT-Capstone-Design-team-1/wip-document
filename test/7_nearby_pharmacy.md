# 기능 동작

## 초기 렌더링 및 내 위치 이동

- 최초 진입 시 위치 권한을 확인하고 로딩 스피너를 노출한 뒤 현재 내 위치로 지도가 이동한다.
- 우측 하단의 '내 위치(GPS)' 플로팅 버튼을 클릭하면 내 위치로 지도의 포커스가 이동한다.

## 마커 및 클러스터링

- 약국이 밀집된 곳에서는 여러 마커가 클러스터(묶음) 아이콘으로 합쳐져 노출된다.
- **클러스터 클릭:** 묶음 마커 클릭 시 해당 위치가 줌 인 되거나 묶여있는 약국들의 리스트 바텀 시트(`PharmacyClusterList`)가 올라와야 한다.
- **단일 약국 클릭:** 개별 마커 클릭 시 하단에 단일 약국 정보 카드(`PharmacyInfoCard`)가 노출된다.
- 정보 카드 내의 '주소 복사' 버튼 클릭 시 클립보드에 복사되었다는 피드백이 발생한다.

## 위치 이동 후 재검색

- 유저가 지도를 스와이프하여 일정 거리 이상 이동할 경우 상단에 "현재 위치에서 검색" 버튼이 표시된다.
- 버튼 클릭 시 이동한 화면 중심을 기준으로 새로운 약국 데이터를 불러오며 버튼이 사라진다.
