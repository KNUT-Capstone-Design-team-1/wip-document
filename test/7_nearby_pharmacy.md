# 테스트 케이스

| 카테고리 | 서브 카테고리 | 테스트 항목 (기대 결과) |
| --- | --- | --- |
| 기능 동작 | 초기 렌더링 및 내 위치 이동 | 최초 진입 시 위치 권한을 확인하고 로딩 스피너를 노출한 뒤 현재 내 위치로 지도가 이동한다. |
| 기능 동작 | 초기 렌더링 및 내 위치 이동 | 우측 하단의 '내 위치(GPS)' 플로팅 버튼을 클릭하면 내 위치로 지도의 포커스가 이동한다. |
| 기능 동작 | 마커 및 클러스터링 | 약국이 밀집된 곳에서는 여러 마커가 클러스터(묶음) 아이콘으로 합쳐져 노출된다. |
| 기능 동작 | 마커 및 클러스터링 | **시각적 디자인:** 개별 마커는 하얀 테두리와 그림자 효과로 시인성을 높였으며, 선택 시 크기가 커진다. 클러스터 마커 역시 하얀 테두리와 굵은(Bold) 텍스트를 적용하여 묶음 개수를 명확히 보여준다. |
| 기능 동작 | 마커 및 클러스터링 | **클러스터 클릭:** 묶음 마커 클릭 시 해당 위치가 줌 인 되거나 묶여있는 약국들의 리스트 바텀 시트(`PharmacyClusterList`)가 올라와야 한다. |
| 기능 동작 | 마커 및 클러스터링 | **클러스터 리스트 고도화:** 바텀 시트 내의 약국 목록은 현재 **내 위치에서 가까운 거리순**으로 자동 정렬(`usePharmacyDistanceSort`)되어 나타나며, 각 약국 이름 옆에 거리(예: `150m`, `1.2km`)가 표시된다. 또한 리스트 항목에서 바로 약국으로 **전화 걸기** 액션이 가능하다. |
| 기능 동작 | 마커 및 클러스터링 | **단일 약국 클릭:** 개별 마커 클릭 시 하단에 단일 약국 정보 카드(`PharmacyInfoCard`)가 노출된다. |
| 기능 동작 | 마커 및 클러스터링 | 정보 카드 내의 '주소 복사' 버튼 클릭 시 클립보드에 복사되었다는 피드백이 발생한다. |
| 기능 동작 | 위치 이동 후 재검색 | 유저가 지도를 스와이프하여 일정 거리 이상 이동할 경우 상단에 "현재 위치에서 검색" 버튼이 표시된다. |
| 기능 동작 | 위치 이동 후 재검색 | 버튼 클릭 시 이동한 화면 중심을 기준으로 새로운 약국 데이터를 불러오며 버튼이 사라진다. |
| 권한 제어 | 위치 접근 권한 | 권한을 허용 했을 때: 정상적으로 위치 기반 주변 약국 검색 기능을 사용할 수 있어야 한다. |
| 권한 제어 | 위치 접근 권한 | 권한을 허용하지 않았을 때: 권한이 필요하다는 안내(모달 등)가 노출되며 설정 화면으로 이동을 유도하거나 기능이 제한되어야 한다. |
| 권한 제어 | 위치 접근 권한 | 권한 허용을 뒤로가기 등 다른 인터렉션으로 무시하고 닫았을 때: 권한 요청이 취소되고 해당 기능이 실행되지 않으며 이전 상태에 머무른다. |
