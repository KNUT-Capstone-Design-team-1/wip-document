# 주변 약국 및 문의 전화 연결

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분         | 확인 절차 및 기대 결과                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 위치 권한    | 허용 시 현재 위치로 이동하고, 거부·취소·위치 조회 실패 시 안내와 화면 사용 상태를 확인한다.            |
| 지도 조회    | 동기화된 약국 데이터가 지도에 표시되고 내 위치 버튼으로 복귀한다.                                      |
| 재검색       | 지도 이동 후 현재 위치에서 검색하면 새 지도 중심을 기준으로 조회한다.                                  |
| 클러스터     | 밀집 마커가 묶이고 선택 시 지도 확대 또는 목록에서 해당 약국을 확인한다.                               |
| 약국 상세    | 약국 카드·목록에서 이름·거리·주소·전화번호·제공된 영업시간을 확인한다.                                 |
| 영업 중 필터 | 평일·주말·공휴일·시간 경계·영업시간 미제공 사례에서 표시와 필터 결과를 확인한다.                       |
| 복사·전화    | 주소 복사 피드백, 전화번호 및 문의 전화 버튼의 기기 전화 앱 연결을 확인한다.                           |
| 재고 문의    | 의약품 상세에서 문의 화면으로 넘어올 때 의약품 요약이 유지된다. 일반 약국 화면과 문의 모드를 구분한다. |
| 데이터 한계  | 영업 여부는 시간표 기반이며 재고 조회 API를 호출하지 않는 현재 동작을 확인한다.                        |

구현 근거: `src/features/nearby_pharmacy/` (앱 저장소).
