# 의약품 검색 결과

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분           | 확인 절차 및 기대 결과                                                                                |
| -------------- | ----------------------------------------------------------------------------------------------------- |
| 진입           | 통합·식별·이미지 검색이 모두 공통 결과 목록으로 연결된다.                                             |
| 목록           | 제품명·회사·이미지·제공된 효능 키워드가 표시되고, 이미지·효능 정보 누락 시 레이아웃이 유지된다.       |
| 빈 결과        | 빈 목록 UI와 대체 검색 안내의 조건을 확인한다.                                                        |
| 로컬 추가 로드 | 식별·이미지 검색 결과에서 하단 도달 시 페이지당 30개씩 추가되며 로딩 중 중복 요청을 막는다.           |
| 통합 추가 로드 | nextCursor와 hasMore를 사용해 추가 조회하고 기존 결과 뒤에 붙인다. 마지막 커서에서 중단한다.          |
| 재검색         | 조건 태그와 검색 조건 수정 UI가 현재 상태를 반영한다. 제품명 재검색·초기화 후 결과와 태그가 일치한다. |
| 상세 진입      | 항목의 ITEM_SEQ와 이미지 정보를 의약품 상세 라우트에 전달한다.                                        |
| 광고·재활용    | 광고가 표시되어도 의약품 키·상세 이동이 섞이지 않고, 광고 미수신 시 목록을 사용할 수 있다.            |

구현 근거: `src/features/pill_search_result_list/`, `src/layouts/header/` (앱 저장소).
