# 테스트 케이스

| 카테고리 | 서브 카테고리 | 테스트 항목 (기대 결과) |
| --- | --- | --- |
| 기능 동작 | 리스트 (검색 결과) | **빈 결과 화면:** 검색 결과가 없을 시 "이런! 검색 결과가 없어요" Empty UI가 정상 노출된다. |
| 기능 동작 | 리스트 (검색 결과) | **무한 스크롤(Pagination):** 리스트 하단(스크롤 약 70% 지점) 도달 시 다음 페이지 데이터를 불러오며, 로딩 중에는 리스트 하단에 Activity Indicator(스피너)가 표시된다. |
| 기능 동작 | 결과 내 검색 조건 수정 (재검색) | **결과 내 재검색:** 리스트 상단의 검색창에서 텍스트 입력 후 검색 시, 기존 검색 조건(식별 필터링 등)이 유지된 상태로 `ITEM_NAME`(제품명) 조건이 추가 결합되어 재조회되어야 한다. |
| 기능 동작 | 결과 내 검색 조건 수정 (재검색) | **재검색 초기화:** 결과 내 재검색 후 텍스트를 지우고 초기화하면, 재검색 이전의 검색 조건과 결과 목록으로 완벽하게 복원되어야 한다. |
