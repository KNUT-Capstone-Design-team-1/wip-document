# 복용 관리 및 알림

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분        | 확인 절차 및 기대 결과                                                                                   |
| ----------- | -------------------------------------------------------------------------------------------------------- |
| 진입        | 보관함의 알림 버튼으로 목록을 열고 새 알림·기존 알림 편집 화면에 진입한다.                               |
| 혼합 대상   | 폴더별 보관 의약품·영양제를 함께 선택하고 이름·업체·대상별 복용량을 확인한다.                            |
| 필수 입력   | 대상·시간·요일이 비어 있으면 저장하지 않는다. 중복 시간과 최대 6개 시간 제한을 확인한다.                 |
| 입력 경계   | 제목 50자·메모 255자, 복용량 1~20의 입력·정제 동작을 확인한다.                                           |
| 예약        | 여러 시간·요일을 저장하고 실제 기기에서 로컬 알림을 수신한다. 권한 거부·재허용, Android 채널도 확인한다. |
| 수정·토글   | 시간·요일 변경과 켜기/끄기 후 이전 예약이 중복 발생하지 않는다.                                          |
| 알림 응답   | 본체 탭 시 해당 reminderId 설정으로 이동하고 ID가 없으면 목록으로 이동한다.                              |
| 다시 알림   | 5분 뒤 재알림을 선택해 단발 알림을 수신한다.                                                             |
| 복용 완료   | 완료 안내 토스트를 확인한다. 복용 이력 저장·통계 증가를 기대 결과로 두지 않는다.                         |
| 삭제·재실행 | 개별·다중·전체 삭제 후 DB와 OS 예약을 확인한다. 앱 재실행과 폴더 삭제 후 남은 일정·예약 상태도 확인한다. |

구현 근거: `src/features/pill_reminder/`, `src/features/setting/hooks/use_setting.ts` (앱 저장소).
