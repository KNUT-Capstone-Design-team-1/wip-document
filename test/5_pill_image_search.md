# AI 알약 이미지 검색

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분      | 확인 절차 및 기대 결과                                                                        |
| --------- | --------------------------------------------------------------------------------------------- |
| 권한      | 카메라 권한 허용·거부·요청 취소를 각각 확인한다. 앨범·파일 선택 취소 시 기존 사진을 보존한다. |
| 사진 등록 | 카메라·앨범·파일에서 앞면과 뒷면을 등록하고 미리보기·교체·삭제를 확인한다.                    |
| 여러 사진 | 두 장 선택 시 앞뒷면 슬롯에 순서대로 등록된다.                                                |
| 입력 부족 | 한 면이라도 없으면 검색을 진행하지 않고 앞뒷면이 모두 필요하다는 토스트를 표시한다.           |
| 검색 흐름 | 원격 AI에서 외형 특징을 받은 뒤 로컬 후보를 검색하고 공통 검색 결과 목록으로 이동한다.        |
| 로딩·광고 | 분석 중 전체 로딩을 표시하며 광고 표시·종료·미수신 상황에서도 완료 후 로딩이 해제된다.        |
| 인식 실패 | 추출 조건이 비면 재촬영·식별 검색 안내 토스트를 표시하고 검색 화면에 머문다.                  |
| API 실패  | 이미지 분석 실패 토스트를 표시하고 로딩·검색 중 상태가 해제된다.                              |
| 후보 선택 | 결과 항목을 선택해야 의약품 상세로 이동한다.                                                  |

구현 근거: `src/features/pill_image_search/hooks/usePillImageActions.ts` (앱 저장소).
