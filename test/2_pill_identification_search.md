# 입력 값 밸리데이션

## 식별 문자 (앞면, 뒷면)

- 글자수 제한: 최대 50자 입력 가능

## 제품명

- 글자수 제한: 최대 50자 입력 가능

## 제조사명

- 글자수 제한: 최대 50자 입력 가능

---

# 기능 동작

## 식별 문자

- 앞면 문자와 뒷면 문자 상관 없이 검색된다 (`%LIKE%`)
- **`식별문자 일치` 체크박스:** 활성화 시 입력된 값과 정확히 일치하는 알약만 검색되도록 필터링(`PRINT_FRONT_EXACTLY`, `PRINT_BACK_EXACTLY`)이 변경된다. 빈 값은 무시된다.

## 제품명

- `%LIKE%` 검색이 수행된다

## 제조사명

- `%LIKE%` 검색이 수행된다

## 다중 선택 항목 (제형, 분할선, 모양, 색상 등)

- '전체' 버튼 선택 시 다른 선택된 항목이 모두 해제되어야 한다.
- '전체' 이외의 항목들은 중복(다중) 선택이 가능해야 한다.
- 이미 선택된 항목을 다시 탭하면 선택이 해제되어야 한다.

## 검색 실행 및 초기화

- 텍스트 입력값과 다중 선택 항목들이 `AND` 조건으로 올바르게 결합되어 검색 요청이 전송되는지 확인한다.
- **초기화(Reset) 버튼:** 클릭 시 텍스트 입력 필드, 선택된 다중 항목, 마크 등이 모두 빈 값이나 '전체' 상태로 정상 초기화되어야 한다.
