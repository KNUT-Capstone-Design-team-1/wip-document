# 홈·공지·가이드·공통 기능

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분        | 확인 절차 및 기대 결과                                                             |
| ----------- | ---------------------------------------------------------------------------------- |
| 홈          | 통합·식별·이미지·영양제 검색 진입과 최근 조회 의약품 상세 연결을 확인한다.         |
| 공지        | 목록·상세·필독 표시와 메인 필독 바텀시트를 확인한다. 빈 목록·통신 실패도 확인한다. |
| 가이드      | 지원 화면의 최초 자동 시작, 다음·이전·완료·건너뛰기와 도움말 다시 보기를 확인한다. |
| 가이드 기록 | 같은 once 투어 버전은 재시작 후 자동 재노출되지 않고, 버전을 올리면 다시 노출된다. |
| 오버레이    | 긴 화면 스크롤과 Android·iOS의 강조 위치, 공통 모달·로딩·토스트 겹침을 확인한다.   |
| 광고        | 광고 로드·미수신·종료 후에도 검색과 상세 이동이 정상 완료된다.                     |
| 외부 연결   | 정보 페이지·스토어 연결과 뒤로 복귀를 확인한다.                                    |

구현 근거: `src/features/home/`, `src/features/notice/`, `src/features/guide/`, `src/features/ads/`, `app/_layout.tsx` (앱 저장소).
