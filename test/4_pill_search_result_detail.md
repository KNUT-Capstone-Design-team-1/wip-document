# 의약품 상세 정보

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분           | 확인 절차 및 기대 결과                                                                                    |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| 데이터 분리    | 로컬 기본 정보와 원격 효능·용법·주의 문서가 각각 로딩되며, 원격 실패 시 사용 가능한 기본 정보가 유지된다. |
| 이미지         | 이미지가 없으면 대체 UI를 표시한다.                                                                       |
| 정보 표시      | 기본 허가·성분·포장·저장 정보와 제공된 상세 문서를 확인한다. 누락 필드를 허위 값으로 채우지 않는다.       |
| 참고 분류      | 마약류·도핑·스테로이드 성분과 운전 주의 문구의 해당·비해당·자료 누락 사례를 비교한다.                     |
| 키워드 찾기    | 상세 내 키워드 검색·강조·다음/이전 이동과 결과 없음 상태를 확인한다.                                      |
| 저장           | 저장 버튼으로 폴더 선택 모달을 열어 저장·해제하고 재진입 시 상태가 유지된다.                              |
| 재고 문의      | 안내 모달 후 선택 의약품 정보를 가진 약국 문의 화면으로 이동하고 전화 앱을 연다.                          |
| 캐시·전환      | 같은 품목 재진입과 서로 다른 품목의 빠른 전환에서 다른 의약품의 상세가 섞이지 않는다.                     |
| 안내·외부 연결 | 의료 정보 안내 문구와 제공된 외부 정보 링크를 확인한다.                                                   |

구현 근거: `src/features/pill_search_result_detail/` (앱 저장소).
