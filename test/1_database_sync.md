# 밸리데이션 및 예외 처리

- **데이터 무결성 검증:** 페이지별 데이터 삽입 완료 후, 실제 로컬 DB(SQLite)에 저장된 데이터 수와 서버 API가 응답한 기대 카운트가 다를 경우 `[VERIFICATION_FAILED]` 에러를 감지하고, 해당 테이블의 데이터를 롤백 후 재시작하는지 확인한다.
- **네트워크 및 기타 에러:** 데이터 동기화 중 심각한 실패(또는 반복 실패)가 발생할 경우 "데이터 동기화에 실패했습니다. 앱을 재시작해 주세요." 에러 안내가 발생하는지 확인한다.

# 기능 동작

## 진행률 및 UI

- 여러 테이블을 페이지 단위로 쪼개어 업데이트하면서 전체 진행률(%) 수치와 프로그레스 바 영역이 부드럽게(Animated) 채워지는지 확인한다.
- 화면 중앙에 "약 이름이 궁금할 땐 이게뭐약?" 문구 및 애니메이션 로고 이미지가 정상 렌더링되는지 확인한다.

## 제어 및 완료

- **이어받기(Resume):** 동기화 도중 앱이 종료되더라도, 재시작 시 실패한 지점이나 중단된 테이블부터 정상적으로 이어받아 업데이트를 수행하는지 확인한다.
- 업데이트가 모두 끝나면 '완료' 상태로 변경되며 메인 앱 화면으로 자동 진입(`setIsInitializing(false)`) 되는지 확인한다.
