# 제약 조건 및 밸리데이션

## 개수 제한 정책

- **최대 폴더 개수:** 폴더는 최대 100개까지만 생성할 수 있습니다. 초과하여 생성 시도 시 "폴더는 최대 100개까지만 생성할 수 있습니다." 에러 처리
- **폴더 당 최대 알약 개수:** 하나의 폴더에는 최대 1,000개의 알약을 보관할 수 있습니다. 알약 저장/이동/복사 시 이를 초과하면 "알약 보관함 폴더 내 알약 개수는 최대 1000개입니다. ({폴더명})" 에러 처리
- **폴더 다중 선택 제한:** 알약을 복사(copy)할 때 다중 선택할 수 있는 폴더는 최대 20개로 제한됩니다. 초과 선택 시 "최대 20개의 폴더만 선택할 수 있습니다." 에러 처리

## 폴더 이름 (`validateFolderName`)

- **글자수 제한:** 최대 255자 입력 가능 (`maxLength` 제한 적용)
- **빈 값:** 빈 칸이나 공백만 입력 시 "폴더 이름을 입력해주세요." 에러 처리
- **특수문자:** `()`, `[]`, `<>`, `!`, `@` 등 일반적인 특수문자는 허용되나, SQL에 문제를 일으킬 수 있는 따옴표(`'`, `"`), 세미콜론(`;`), 백틱(```) 등은 "폴더 이름에 허용되지 않는 특수문자가 포함되어 있습니다." 에러 처리
- **중복 검사:** 이미 존재하는 폴더 이름 입력 시 "이미 존재하는 폴더 이름입니다." 에러 처리

# 기능 동작

## 폴더 기본 규칙

- **'기본 폴더' 제약:** 앱에서 제공하는 '기본 폴더'는 이름 변경, 삭제, 다중 선택이 불가능하다. 기본 폴더를 꾹 누르거나(Long Press) 선택 시 "기본 폴더는 수정할 수 없습니다. 새로운 폴더를 만들어주세요" 에러 토스트 메시지가 발생한다.

## 생성 및 수정

- '새 폴더 추가' 시 모달 팝업 및 포커싱 처리되며, 정상 통과 시 즉시 리스트에 반영된다.
- 키보드 활성화 시 텍스트 입력창이 가려지지 않도록 모달과 바텀 시트가 화면 위로 밀려 올라온다 (`KeyboardAvoidingView` 적용).
- '폴더 이름 변경' 시 모달의 텍스트 인풋에 기존 폴더 이름이 채워진 채로 렌더링된다.

## 리스트 뷰 동작 (폴더 및 저장된 알약 목록)

- **정렬:** 리스트의 기본 정렬 순서는 **'최신순'(`createdAt_desc`)**이며, 정렬 모달(`FolderSortModal`)을 통해 정렬 방식을 변경하면 즉시 렌더링 순서가 바뀐다.
- **편집 모드:** '편집' 모드 진입 시 앱 하단 탭바(Bottom Tab Nav)가 숨겨지고, 다중 선택 상태 바(Delete/Rename/Move/Copy)가 노출된다. 편집 바텀 바에 현재 '선택된 폴더 개수'가 정확하게 표시된다.
- **알약 이동/복사:** 보관된 알약을 다른 폴더로 '이동(move)'할 때는 한 번에 하나의 폴더만 선택 가능하며, '복사(copy)'할 때는 다중 선택이 가능하다.
- **삭제 모달:** 폴더나 알약 삭제 시도 시 '정말 삭제하시겠습니까' 형식의 재확인 알림 모달이 노출된다. 이때 삭제 확인 버튼은 빨간 테두리의 투명한 배경 스타일로 렌더링된다.
- 폴더 진입 시 저장된 알약 리스트가 노출되며, 해당 알약들을 탭하여 상세 정보를 확인하거나 리스트에서 다중 선택하여 삭제/이동/복사할 수 있다.
