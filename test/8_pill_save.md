# 입력 값 밸리데이션 (`validateFolderName`)

## 폴더 이름

- 글자수 제한: 최대 255자 입력 가능
- **빈 값:** 빈 칸이나 공백만 입력 시 "폴더 이름을 입력해주세요" 에러 처리
- **특수문자:** 특수문자 입력 시 "폴더 이름에 특수문자는 사용할 수 없습니다" 에러 처리
- **중복 검사:** 이미 존재하는 폴더 이름 입력 시 "이미 존재하는 폴더 이름입니다" 에러 처리

# 기능 동작

## 폴더 기본 규칙

- **'기본 폴더' 제약:** 앱에서 제공하는 '기본 폴더'는 이름 변경, 삭제, 다중 선택이 불가능해야 하며 시도 시 에러 토스트 메시지가 발생해야 한다.

## 생성 및 수정

- '새 폴더 추가' 시 모달 팝업 및 포커싱 처리, 정상 통과 시 즉시 리스트에 반영된다.
- '폴더 이름 변경' 시 모달의 텍스트 인풋에 기존 폴더 이름이 채워진 채로 렌더링된다.

## 리스트 뷰 동작 (폴더 및 저장된 알약 목록)

- **편집 모드:** '편집' 모드 진입 시 앱 하단 탭바(Bottom Tab Nav)가 숨겨지고, 다중 선택 상태 바(Delete/Rename)가 노출된다.
- 편집 바텀 바에 현재 '선택된 폴더 개수'가 정확하게 표시된다.
- **정렬:** 이름순, 최신순 등 폴더 정렬 모달(`FolderSortModal`)을 통해 정렬 방식을 변경하면 즉시 리스트의 렌더링 순서가 바뀐다.
- 폴더 삭제 시도 시 '정말 삭제하시겠습니까' 형식의 재확인 알림 모달이 노출된다.
- 폴더 진입 시 저장된 알약 리스트가 노출되며, 해당 알약들을 탭하여 상세 정보를 확인하거나 리스트에서 삭제할 수 있는지 확인한다.
