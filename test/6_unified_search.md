# 의약품 통합 검색

수동 검증 시나리오입니다. 코드 대조로 정리했으며 기기에서 통과한 결과를 의미하지 않습니다.

| 구분         | 확인 절차 및 기대 결과                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 입력         | 입력창 최대 50자, 공백만 입력 시 검색 미실행, 검색·초기화 아이콘과 키보드 검색 동작을 확인한다.                                |
| 검색어 처리  | 앞뒤 공백 제거 후 공백 기준 최대 5개 키워드를 원격 API에 전달한다.                                                             |
| 최근 검색어  | 성공한 요청의 검색어가 저장되고 최근 검색어 선택으로 다시 검색한다. 최근 조회 의약품과 구분한다.                               |
| 로컬 결합    | 서버가 반환한 품목번호로 로컬 기본 정보를 조회한다. 원격 번호 중 로컬에 없는 항목도 시험한다.                                  |
| 추가 조회    | 최초 요청 limit은 100이며 nextCursor·hasMore에 따라 다음 결과를 불러온다. 최대 50건 고정 제한으로 검증하지 않는다.             |
| 빈 결과·실패 | 빈 결과는 안내 토스트 후 현재 화면 유지, 원격 실패는 오류 안내와 로딩 해제를 확인한다.                                         |
| 라우팅       | /unified-search에서는 결과를 push, 결과 화면에서는 현재 화면 유지, 그 밖의 경로에서는 결과로 replace하는 현재 분기를 확인한다. |
| 조건 상태    | 새 키워드 검색 시 이전 페이지·커서·검색 결과가 초기화된다.                                                                     |

구현 근거: `src/features/unified_search/hooks/useUnifiedSearch.ts`, `services/unifiedSearchService.ts` (앱 저장소).
