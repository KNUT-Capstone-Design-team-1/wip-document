# 1. 데이터베이스 업데이트 (Database Sync)

## 밸리데이션 및 예외 처리

- **데이터 무결성 검증:** 페이지별 데이터 삽입 완료 후, 실제 로컬 DB(SQLite)에 저장된 데이터 수와 서버 API가 응답한 기대 카운트가 다를 경우 `[VERIFICATION_FAILED]` 에러를 감지하고, 해당 테이블의 데이터를 롤백 후 재시작하는지 확인한다.
- **네트워크 및 기타 에러:** 데이터 동기화 중 심각한 실패(또는 반복 실패)가 발생할 경우 "데이터 동기화에 실패했습니다. 앱을 재시작해 주세요." 에러 안내가 발생하는지 확인한다.

## 기능 동작

#### 진행률 및 UI

- 여러 테이블을 페이지 단위로 쪼개어 업데이트하면서 전체 진행률(%) 수치와 프로그레스 바 영역이 부드럽게(Animated) 채워지는지 확인한다.
- 화면 중앙에 "약 이름이 궁금할 땐 이게뭐약?" 문구 및 애니메이션 로고 이미지가 정상 렌더링되는지 확인한다.

#### 제어 및 완료

- **이어받기(Resume):** 동기화 도중 앱이 종료되더라도, 재시작 시 실패한 지점이나 중단된 테이블부터 정상적으로 이어받아 업데이트를 수행하는지 확인한다.
- 업데이트가 모두 끝나면 '완료' 상태로 변경되며 메인 앱 화면으로 자동 진입(`setIsInitializing(false)`) 되는지 확인한다.

# 2. 식별검색 (`PillIdentificationSearchScreen`)

## 입력 값 밸리데이션

#### 식별 문자 (앞면, 뒷면)

- 글자수 제한: 최대 50자 입력 가능

#### 제품명

- 글자수 제한: 최대 50자 입력 가능

#### 제조사명

- 글자수 제한: 최대 50자 입력 가능

---

## 기능 동작

#### 식별 문자

- 앞면 문자와 뒷면 문자 상관 없이 검색된다 (`%LIKE%`)
- **`식별문자 일치` 체크박스:** 활성화 시 입력된 값과 정확히 일치하는 알약만 검색되도록 필터링(`PRINT_FRONT_EXACTLY`, `PRINT_BACK_EXACTLY`)이 변경된다. 빈 값은 무시된다.

#### 제품명

- `%LIKE%` 검색이 수행된다

#### 제조사명

- `%LIKE%` 검색이 수행된다

#### 다중 선택 항목 (제형, 분할선, 모양, 색상 등)

- '전체' 버튼 선택 시 다른 선택된 항목이 모두 해제되어야 한다.
- '전체' 이외의 항목들은 중복(다중) 선택이 가능해야 한다.
- 이미 선택된 항목을 다시 탭하면 선택이 해제되어야 한다.

#### 검색 실행 및 초기화

- 텍스트 입력값과 다중 선택 항목들이 `AND` 조건으로 올바르게 결합되어 검색 요청이 전송되는지 확인한다.
- **초기화(Reset) 버튼:** 클릭 시 텍스트 입력 필드, 선택된 다중 항목, 마크 등이 모두 빈 값이나 '전체' 상태로 정상 초기화되어야 한다.

# 3. 검색 결과 목록 (`SearchResultList`)

## 기능 동작

#### 리스트 (검색 결과)

- **빈 결과 화면:** 검색 결과가 없을 시 "이런! 검색 결과가 없어요" Empty UI가 정상 노출된다.
- **무한 스크롤(Pagination):** 리스트 하단(스크롤 약 70% 지점) 도달 시 다음 페이지 데이터를 불러오며, 로딩 중에는 리스트 하단에 Activity Indicator(스피너)가 표시된다.

#### 결과 내 검색 조건 수정 (재검색)

- **결과 내 재검색:** 리스트 상단의 검색창에서 텍스트 입력 후 검색 시, 기존 검색 조건(식별 필터링 등)이 유지된 상태로 `ITEM_NAME`(제품명) 조건이 추가 결합되어 재조회되어야 한다.
- **재검색 초기화:** 결과 내 재검색 후 텍스트를 지우고 초기화하면, 재검색 이전의 검색 조건과 결과 목록으로 완벽하게 복원되어야 한다.

# 5. 이미지 검색 (`PillImageSearchScreen`)

## 밸리데이션 및 예외 처리

- 카메라 및 갤러리 접근 권한이 없을 경우 적절한 권한 요청 및 안내가 발생해야 한다.

---

## 기능 동작

#### 사진 업로드

- 앞면과 뒷면 사진 영역을 각각 탭하여 정상적으로 이미지가 업로드되는지 확인한다.
- 선택된 이미지가 각 영역에 미리보기(Preview)로 표시되어야 한다.
- 미리보기 상단의 `x` 버튼을 눌러 선택된 이미지를 삭제할 수 있어야 한다.

#### 검색 실행

- **다중 이미지 선택:** 갤러리에서 여러 장의 이미지를 동시에 선택 시 첫 2장만 앞/뒷면에 순차 등록되는지 확인한다.
- **검색 버튼 활성화 조건:** 앞면과 뒷면 이미지가 모두 등록되어야만 하단의 '적용(검색)' 버튼이 표시되거나 활성화된다. (한 면이라도 없을 경우 '알약의 앞면과 뒷면 이미지가 모두 필요합니다' 경고 모달 노출)
- **로딩 및 광고 처리:** 검색 실행 시 화면을 덮는 풀 스크린 로딩('이미지를 분석하여 알약을 찾는 중입니다...')이 뜨며, 전면 광고(`Interstitial Ad`)를 호출한다. 전면 광고를 닫으면 검색 결과로 넘어가는지 확인한다.
- **오류 처리:** 이미지 분석(API 호출) 실패 시 '이미지 분석에 실패했습니다. 다시 시도해 주세요.' Alert 모달이 뜨며 검색 화면에 머무르는지 확인한다.
- (TODO) 검색 중 뒤로가기나 외부 이탈 시 로딩이 멈추거나 검색이 중도 취소(Cancel)되는지 확인한다.

# 6. 통합 검색 (`UnifiedSearchBar`)

## 입력 값 밸리데이션

#### 검색어

- 글자수 제한: 최대 50자 입력 가능
- 엔터키(줄바꿈 `\n`) 입력 시 검색어에 포함되지 않고 즉시 검색 동작으로 처리되어야 한다.

---

## 기능 동작

#### 검색창 UI

- 포커스(입력 중) 상태일 때 검색창 테두리 색상이 Primary 색상으로 변경된다.
- 검색어 입력 전: 우측에 '돋보기' 아이콘 표시
- 검색어 입력 후: 우측에 'X(초기화)' 아이콘으로 변경되며, 클릭 시 입력된 내용이 모두 지워진다.

#### 검색 실행

- 키보드의 '검색(엔터)' 버튼 터치 시 정상적으로 검색이 실행되어야 한다.
- 텍스트가 완전히 비어있거나 공백만 있는 상태에서는 검색이 실행되지 않아야 한다.
- **다중 키워드 검색:** 띄어쓰기를 기준으로 여러 단어를 입력할 경우, 각각의 단어가 결합되어 정상적으로 검색되는지 확인한다.
- **빈 검색 결과:** 검색 결과가 하나도 없을 경우 토스트 메시지('입력하신 키워드와 일치하는 약 정보가 없습니다.')가 뜨고 다른 화면으로 이동하지 않는다.
- **결과 제한:** 통합 검색의 경우 무한 스크롤(페이지네이션)이 적용되지 않고 최대 50건까지만 화면에 렌더링 되어야 한다 (`hasMore: false`).
- **라우팅 처리:** 홈 화면(`/`)에서 검색 시 검색 결과 페이지가 스택에 추가(push)되어 뒤로가기가 가능해야 하며, 다른 탭에서 검색 시 현재 화면이 교체(replace)되어야 한다.

# 7. 내 주변 약국 (`NearbyPharmacyScreen`)

## 기능 동작

#### 초기 렌더링 및 내 위치 이동

- 최초 진입 시 위치 권한을 확인하고 로딩 스피너를 노출한 뒤 현재 내 위치로 지도가 이동한다.
- 우측 하단의 '내 위치(GPS)' 플로팅 버튼을 클릭하면 내 위치로 지도의 포커스가 이동한다.

#### 마커 및 클러스터링

- 약국이 밀집된 곳에서는 여러 마커가 클러스터(묶음) 아이콘으로 합쳐져 노출된다.
- **클러스터 클릭:** 묶음 마커 클릭 시 해당 위치가 줌 인 되거나 묶여있는 약국들의 리스트 바텀 시트(`PharmacyClusterList`)가 올라와야 한다.
- **단일 약국 클릭:** 개별 마커 클릭 시 하단에 단일 약국 정보 카드(`PharmacyInfoCard`)가 노출된다.
- 정보 카드 내의 '주소 복사' 버튼 클릭 시 클립보드에 복사되었다는 피드백이 발생한다.

#### 위치 이동 후 재검색

- 유저가 지도를 스와이프하여 일정 거리 이상 이동할 경우 상단에 "현재 위치에서 검색" 버튼이 표시된다.
- 버튼 클릭 시 이동한 화면 중심을 기준으로 새로운 약국 데이터를 불러오며 버튼이 사라진다.

# 8. 알약 보관함 (`PillSaveScreen`, `FolderEditModal` 등)

## 입력 값 밸리데이션 (`validateFolderName`)

#### 폴더 이름

- 글자수 제한: 최대 255자 입력 가능
- **빈 값:** 빈 칸이나 공백만 입력 시 "폴더 이름을 입력해주세요" 에러 처리
- **특수문자:** 특수문자 입력 시 "폴더 이름에 특수문자는 사용할 수 없습니다" 에러 처리
- **중복 검사:** 이미 존재하는 폴더 이름 입력 시 "이미 존재하는 폴더 이름입니다" 에러 처리

---

## 기능 동작

#### 폴더 기본 규칙

- **'기본 폴더' 제약:** 앱에서 제공하는 '기본 폴더'는 이름 변경, 삭제, 다중 선택이 불가능해야 하며 시도 시 에러 토스트 메시지가 발생해야 한다.

#### 생성 및 수정

- '새 폴더 추가' 시 모달 팝업 및 포커싱 처리, 정상 통과 시 즉시 리스트에 반영된다.
- '폴더 이름 변경' 시 모달의 텍스트 인풋에 기존 폴더 이름이 채워진 채로 렌더링된다.

#### 리스트 뷰 동작 (폴더 및 저장된 알약 목록)

- **편집 모드:** '편집' 모드 진입 시 앱 하단 탭바(Bottom Tab Nav)가 숨겨지고, 다중 선택 상태 바(Delete/Rename)가 노출된다.
- 편집 바텀 바에 현재 '선택된 폴더 개수'가 정확하게 표시된다.
- **정렬:** 이름순, 최신순 등 폴더 정렬 모달(`FolderSortModal`)을 통해 정렬 방식을 변경하면 즉시 리스트의 렌더링 순서가 바뀐다.
- 폴더 삭제 시도 시 '정말 삭제하시겠습니까' 형식의 재확인 알림 모달이 노출된다.
- 폴더 진입 시 저장된 알약 리스트가 노출되며, 해당 알약들을 탭하여 상세 정보를 확인하거나 리스트에서 삭제할 수 있는지 확인한다.

# 9. 설정 (Settings)

## 기능 동작

#### 설정 항목 클릭
